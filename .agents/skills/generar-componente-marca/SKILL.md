# Skill: generar-componente-marca

Esta skill guía al agente en la creación de componentes visuales en React (Next.js) adaptados específicamente a la identidad visual de **Sergio Decoraciones**.

## Instrucciones de diseño y estilo:
1. Aplica la paleta de colores oficial de la marca: Ocre Profundo (`#815922`), Negro Carbón (`#1A1A1A`), Blanco Puro (`#FFFFFF`) y Gris Grafito (`#6C6D6F`) utilizando las variables CSS correspondientes.
2. Utiliza las familias tipográficas correctas: **Cinzel** en negrita exclusivamente para títulos principales y destacados, y **Lato** para textos y párrafos generales.
3. Asegura un diseño totalmente responsivo bajo el enfoque *mobile first* (desde 360 px) con contraste adecuado y soporte para navegación por teclado.
