# Comando /spec

Lee la descripción del requerimiento brindada por el usuario y genera la especificación técnica completa en la carpeta correspondiente (`specs/NNN-nombre/spec.md`). 

La especificación debe incluir obligatoriamente:
1. Contexto y objetivos.
2. Historias de usuario.
3. Requisitos funcionales y no funcionales utilizando la notación EARS.
4. Casos límite (edge cases) y elementos fuera de alcance.
5. Criterios de finalización claros ("Listo cuando...").
