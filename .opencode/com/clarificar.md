# Comando /clarificar

Actúa como un analista QA riguroso. Revisa la especificación técnica actual (`specs/NNN-nombre/spec.md`) en busca de ambigüedades, contradicciones, lagunas técnicas o requerimientos imprecisos. 

Genera como resultado el archivo `clarificacion.md` detallando tus hallazgos, preguntas abiertas y propuestas de solución para que el estudiante (Sergio / Gastón) tome una decisión sobre cada punto.
